job-pipeline — pipeline architecture

hunt → tailor → submit, with the job status lifecycle as the connecting spine

Legend: yellow subgraphs are in-repo stages (jobpipe/hunt, jobpipe/tailor, jobpipe/submit, jobpipe/shared); grey boxes are external systems (Supabase, Anthropic, GitHub Actions, SerpAPI/JSearch, Resend); the amber box is the canonical status.py enum that every stage transition keys off. Green boxes mark the two most recent additions to submit: the post-decision browser-truth gate and the fill-rate drift aggregator. Every edge is labeled with what actually crosses it — a status transition, an API/LLM call, or a data payload.
